フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストを 1 つのブランチに保存しました。これらをまとめてレビューし、プルリクエストを作成します。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスを任せます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを複数の PR に分けます。ワークショップを円滑に進めるため、フィルター機能と品質ワークフロー全体を 1 つのセッションとブランチで進め、そのすべての作業をこの PR にまとめました。

このレッスンでは、次のことを行います。

- Agent Merge と、マージのライフサイクルを自動化する方法を学びます。
- 機能全体の PR と検証の根拠を確認します。
- レビュー後にのみ Agent Merge を許可し、PR がマージされたことを確認します。

## シナリオ

フィルター機能のワークフロー全体を通じて、Copilot を使って機能を計画、実装、検証しました。Tailspin Toys は、マージの許可を開発者の管理下に置きながら、残りの PR 作業を自動化したいと考えています。

## Agent Merge とは

**Agent Merge** は、GitHub Copilot app でプルリクエストをマージするまでの残りの作業を自動化します。有効にすると、アプリのセッションがプルリクエストを読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビューコメントへの対応、必要に応じたリベースなど、マージを妨げる問題に対処します。その後、GitHub で許可され次第マージします。バックグラウンドで実行され、アプリを再起動しても継続し、プルリクエストがマージされると自動的に停止します。

ここまでは、自分で **Merge pull request** を選択していました。Agent Merge にその役割を任せることもできます。ただし、コードの編集やマージを実行するには、引き続き明示的な許可が必要です。マージ権限を与える前に、Agent Merge に許可する操作と作業をレビューしてください。

## Agent Merge で PR を管理する

コードの作成とレビューが終わったら、Agent Merge に PR の残りの作業を任せます。

1. エージェントピッカーで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択して処理を開始します。ドロップダウンから選択するだけでは開始されません。

Agent Merge の処理が開始され、次の作業を行います。

- タイトルと説明を含むプルリクエストを作成します。
- Issue からセッションを開始した場合は、説明の本文で関連する Issue を参照します。
- リベースを行うか、ターゲットブランチとのマージ競合に対処します。
- CI を監視して、すべてのチェックが成功するようにします。
- 他の開発者や Copilot code review からのフィードバックがないか PR を監視し、コメントを解決するために更新します。
- すべてが成功したら、任意で PR を自動的にマージします。

すべてのチェックに成功した後で、Agent Merge が PR をマージすることも許可します。

5. マージを許可する前に、PR の差分と検証の根拠をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. 次のように明示して、エージェントにマージを依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 作業の進行状況を確認し、報告された問題を解決します。続行する前に PR の状態が **Merged** になっていることを確認します。マージ権限を有効にしたことやエージェントが実行中であることだけでは、マージが完了した証拠になりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前にそれらの問題を解決してください。
