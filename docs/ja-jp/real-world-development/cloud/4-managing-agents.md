前の数回の演習では、ユーザーエクスペリエンスの改善と機能追加を目的に、GitHub Copilot クラウドエージェントへ 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に動作しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールを使って管理できます。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。エージェントの実行内容を調べたり、進行中のセッションを誘導したりできます。

このレッスンでは、次のことを行います。

- エージェントページを開き、クラウドエージェントのタスクを監視します。
- 実行中のセッションを誘導し、機能の追加を依頼します。

## シナリオ

ハイコントラストモードの作成をエージェントに依頼した後、チームはライトモードも追加するとよいと気付きました。サイトのスタイルと切り替え機能を更新しているため、ライトモードも含めるのが合理的です。エージェントを誘導し、ハイコントラストモードとライトモードの両方を追加します。

## GitHub Copilot クラウドエージェントのタスクを確認する

GitHub Copilot クラウドエージェントに割り当てたタスクの現在の状態を確認しましょう。

1. [Copilot エージェントページ](https://github.com/copilot/agents)を開きます。
2. メインペインと左側のペインにあるタスク一覧を確認します。次のようなタスクが表示されます。
    - コードのドキュメントを更新する。
    - ゲームを操作する API を生成する。
    - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が実行した作業を確認します。次のような作業が含まれます。
    - リポジトリからコードをチェックアウトする。
    - Copilot が作業する環境を作成する。
    - MCP サーバーをセットアップする。
    - 割り当てられたタスクを完了するための作業を行う。

> [!NOTE]
> 表示される具体的な手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここから PR と変更ファイルを確認し、作業を監視できます。

## クラウドエージェントを誘導する

実行中のタスクを確認できました。次に、高コントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードを追加するセッションを選択します。Copilot が付けた名前や作業状態によって、セッションのタイトルは異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![エージェントページで、作業中のセッションを誘導するダイアログが強調表示されたクラウドエージェントのタスク画面](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業手順に含めることを確認します。

## Copilot の作業を待つ

前と同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で進めていた手順が終わると、新しい依頼が作業の流れに反映されます。

今回も完了まで数分かかります。これまでに学んだことを振り返りながら待ちましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウドエージェントのタスクを監視して誘導するための中心的な場所である、Copilot エージェントページを確認しました。ミッションコントロールでは、進行中および完了したタスクを追跡し、実行中の作業をレビューし、セッションの進行中に依頼内容を調整したり追加のガイダンスを与えたりできます。

このレッスンでは、次のことを確認しました。

- ミッションコントロールとエージェントページでクラウドエージェントのタスクを監視する。
- 実行中のセッションを誘導し、機能の追加を依頼する。

Copilot がアクセシビリティ機能を実装している間に、[Copilot が作成したプルリクエストを改善する][next-lesson]方法を確認しましょう。
