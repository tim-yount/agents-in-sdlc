多くの CLI ツールと同様に、GitHub Copilot CLI にもさまざまなスラッシュコマンドがあります。高度な機能、内部情報、追加の構成オプションを利用できます。これまで `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ここでは、ほかの便利なコマンドを確認します。

このレッスンでは、次のことを行います。

- `/context` と `/compact` で、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` で、利用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、worktree、クラウドエージェントへの委任に使える任意のコマンドを確認します。

## シナリオ

CLI の中心的なワークフローを終えました。次に、コンテキスト管理、モデルの切り替え、セッション共有などの機能を確認します。任意で [Copilot クラウドエージェント][about-cloud-agent]に作業を委任することもできます。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルが処理できるコンテキストの上限に達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。また、スラッシュコマンドで状態を確認したり、自分で圧縮したりできます。

1. Codespace に戻り、まだ開いていない場合はリポジトリルートから Copilot CLI を起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域へのコンテキストの配分を確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を実行して結果を比較します。会話が短い場合、大きな違いはないことがあります。

> [!NOTE]
> コンテキストウィンドウが埋まると、Copilot CLI は自動的にコンテキストを圧縮します。自分でタイミングを選ぶ場合は `/compact` を使います。無関係なタスクに切り替えるために新しい会話を始めたい場合は、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者によって好みも違います。Copilot CLI では、利用可能なモデルを一覧表示して選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況に関する情報を確認します。
3. 現在のモデルを維持するか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで作業し、学んだことを共有すると、全員が AI ツールをより効果的に使えるようになります。`/share` コマンドでは、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist として公開したりできます。

1. `/help` を入力し、インストール済みバージョンの `/share` オプションを確認します。
2. セッションを共有する場合は、ローカルの Markdown へのエクスポートなら `/share file` など、目的に合う方法を選択します。
3. エクスポートした内容を、誰かに送信したり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれることがあります。

リンクや gist の公開は任意です。チームが共有するつもりのないリポジトリや会話の内容を公開しないでください。

## 任意: 作業の並列化や委任

ワークショップの主要な内容は完了しました。Copilot CLI には、大規模なタスク向けに次のコマンドもあります。

- `/fleet` は、独立したサブタスクをサブエージェントに分配して並行実行できます。
- `/worktree` は、別のタスク用に独立した Git worktree を作成できます。
- `/delegate` は、非同期で作業し、プルリクエストを作成することもある Copilot クラウドエージェントにタスクを送信できます。

これらのコマンドは追加の worktree やリモート作業を作成する可能性があるため、任意です。試すときは、範囲を明確にした新しいタスクから始め、通常のワークフローで結果をレビューしてください。非同期エージェントの作業をさらに確認したい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。
